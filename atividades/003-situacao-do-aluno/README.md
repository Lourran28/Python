# Atividade 003 - Situação do aluno

Programa que recebe as notas de dois alunos, valida os valores e informa a situação de cada um pela média.

## Conceitos praticados

- Funções e condicionais
- Laços `for` e `while`
- Validação de dados
- Cálculo de média

## Execução

```bash
python solucao.py
```
