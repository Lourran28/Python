## Sobre o repositório

Este repositório reúne atividades e projetos desenvolvidos durante meus estudos de Python. Aqui pratico lógica de programação, funções, condicionais, estruturas de repetição, listas e dicionários.

Os números das atividades acompanham os arquivos originais, por isso a sequência salta da atividade 007 para a 010.

## Organização

```text
atividades/
└── 001-nome-da-atividade/
    ├── solucao.py
    └── README.md

projetos/
└── nome-do-projeto/
    ├── main.py
    └── README.md
```
