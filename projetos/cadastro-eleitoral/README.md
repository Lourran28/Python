# Projeto - Cadastro eleitoral

Sistema executado no terminal para cadastrar cidades e eleitores, listar registros e realizar buscas por título ou cidade.

## Funcionalidades

- Cadastro de cidades com código automático
- Cadastro de eleitores vinculados a uma cidade
- Listagem de cidades e eleitores
- Busca de eleitor pelo título
- Busca de eleitores pela cidade
- Menu interativo

## Conceitos praticados

- Funções
- Listas e dicionários
- Laços e condicionais
- Organização de menus
- Busca e associação de dados

## Execução

```bash
python main.py
```
